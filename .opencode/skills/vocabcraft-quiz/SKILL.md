# 词汇出考题流程

## Overview

词汇考题生成与评分助手，负责为指定词汇生成多种题型考题并客观评分。核心流程：选题 → 生成考题 → 用户作答 → 评分 → 反馈。支持选择/填空/拼写/释义四种题型，考题由 MCP Tool 动态生成，不硬编码题库。

## When to Use

- 用户说"出题"、"考我"、"测试"、"练一练"、"考题"
- 用户想对指定词汇或随机词汇进行练习
- 用户想主动测试掌握情况（区别于到期复习）

## Workflow

### 1. 确定出题范围
- 指定 `vocab_id`：对该词出题
- 未指定：随机选取若干词汇，或按掌握度筛选薄弱词

### 2. 确定题型
- 用户指定：使用指定题型（choice/fill/spelling/definition）
- 未指定：按词汇 `repetitions` 轮换题型，保证多样性

### 3. 生成考题
调用 `generate_quiz` Tool，传入 `vocab_id` 与 `quiz_type`，获得考题内容。

### 4. 展示考题
以清晰格式展示考题，等待用户作答。

### 5. 评分
调用 `grade_quiz` Tool，传入 `vocab_id` 与用户作答：
- 返回 grade（0-5）与是否正确
- 工具内部按 SM-2 算法更新记忆状态

### 6. 反馈
展示对错、正确答案、grade，询问是否继续下一题。

## Quick Reference

| 步骤 | Tool | 降级方案 |
|------|------|----------|
| 生成考题 | `generate_quiz` | 词汇无例句时填空题降级为释义题 |
| 评分并更新 | `grade_quiz` | - |

## 题型对照

| 题型 | quiz_type | 题目形式 | 评分要点 |
|------|-----------|----------|----------|
| 选择题 | `choice` | 给释义选词，或给词选释义 | 1正确+3干扰，全对满分 |
| 填空题 | `fill` | 例句挖空填词形 | 大小写/单复数容错 |
| 拼写题 | `spelling` | 给释义/发音拼词形 | 字母顺序完全正确 |
| 释义题 | `definition` | 给词形写释义（de/en/zh 等） | 核心义素匹配即对 |
| 释义题 | `definition` | 给例句，选择词性并填写释义（zh_classical） | 词性、释义均正确得 5 分，否则 0 分 |

## Common Mistakes

- **连续同题型**：连续出题不得使用相同题型超过2次（除非用户指定）
- **干扰项明显错误**：选择题干扰项应来自同词性或近义词，避免送分
- **评分受情绪影响**：评分客观，按既定规则给 grade
- **填空题缺例句仍出题**：词汇无 examples 时应降级为释义题
- **文言文作答格式错误**：`zh_classical` 释义题作答必须为 `"词性|释义"`（如 `n.|兵器`），否则判 0 分
- **评分后未更新记忆状态**：每次评分必须触发记忆状态更新

## 约束规则

- 题型多样，连续不超过2次相同题型
- 评分客观，grade 0-5
- 选择题干扰项来自同词性/近义词
- 填空题优先用词汇自带 examples，无则降级释义题
- 评分后必须更新记忆状态
- 详见 AGENTS.md「业务规则 > 复习规则」（评分与记忆状态规则共用）
