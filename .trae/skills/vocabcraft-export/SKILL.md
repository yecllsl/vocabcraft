# 词汇数据导出流程

## Overview

词汇数据导出助手，负责将本地词汇数据导出为 JSON 或 CSV 文件，便于备份与迁移。核心流程：确定格式 → 用户确认 → 导出文件 → 提示位置。导出为破坏性相邻操作（生成文件），必须经用户确认。

## When to Use

- 用户说"导出"、"备份数据"、"导出词汇"、"导出 csv"
- 用户想备份本地词库
- 用户想迁移数据到其他工具（CSV 便于 Excel 查看）

## Workflow

### 1. 确定格式
询问用户导出格式：
- `json`（默认）：完整结构化数据，含记忆状态（repetitions/easiness/next_review_date）
- `csv`：表格形式，便于用 Excel/表格工具查看

### 2. 展示导出范围
展示将导出的内容范围：
- 词汇总数
- 是否含记忆状态（json 含，csv 含核心字段）
- 导出目标路径（`data/exports/`）

### 3. 用户确认
**必须经用户确认后才执行导出**（数据安全规则）。

### 4. 执行导出
调用 `export_data` Tool，传入 `format` 参数。

### 5. 返回结果
返回导出文件路径，提示用户位置与文件大小。

## Quick Reference

| 步骤 | Tool | 降级方案 |
|------|------|----------|
| 导出数据 | `export_data` | 导出失败时提示重试，不损坏原数据 |

## 格式对照

| 格式 | 参数 | 内容 | 适用场景 |
|------|------|------|----------|
| JSON | `json` | 完整结构化 + 记忆状态 | 备份/迁移回本工具 |
| CSV | `csv` | 表格核心字段 | Excel 查看/迁移其他工具 |

## Common Mistakes

- **导出前未确认**：必须经用户确认后才导出
- **导出含个人身份信息**：本项目不记录 PII，导出仅含词汇数据
- **导出文件外传**：导出文件仅保存本地 `data/exports/`，不外传
- **未提示文件位置**：导出后必须返回文件路径告知用户
- **导出失败损坏原数据**：导出为只读原数据的操作，失败不影响词库

## 约束规则

- 导出数据前必须经用户确认
- 导出文件保存到本地 `data/exports/`，不外传
- 不导出个人身份信息（本项目本就不记录）
- 支持 JSON 与 CSV 两种格式
- 详见 AGENTS.md「业务规则 > 数据安全规则」
