# 词汇采集例句关联释义升级

## Context

**问题背景**：
当前 `StructuredVocab` 中 `definitions: list[str]` 与 `examples: list[str]` 是两个平行的字符串数组，例句无法表达"对应哪一个释义"。对于文言文多义词（如"兵"有兵器/士兵/战争/战略四个义项），这是重要信息损失——见 [vocab_20260724_058.json](file:///d:/yecll/Documents/LocalCode/vocabcraft/vocabcraft-mcp/data/vocabs/vocab_20260724_058.json#L7-L22)：8 个例句分属 4 个不同释义，但结构上无法区分。

同时，由于 `parse_vocab` 工具仅渲染 prompt 不实际解析（MCP server 不持有 LLM 凭证，这是合理架构决策），智能体在采集复杂文言文词条时倾向写 Python 脚本完成结构化。用户已确认：**采集流程架构保持现状**，仅通过升级数据结构 + 优化 prompt 输出格式，让智能体直接输出关联结构即可，不再写脚本。

**目标**：
1. `definitions` 升级为 `list[Definition]`，每项 `{text, examples}` 内嵌关联例句
2. 删除顶层 `examples` 字段（Pydantic 模型层），通过 validator 自动归并旧数据，57 个存量文件零迁移
3. 同步升级 parse_vocab prompt 输出格式，让智能体按新结构直接输出 JSON
4. 同步更新出题/导出/Web 展示/Web 编辑逻辑，利用例句与释义的关联

**用户决策**（已确认）：
- 采集流程架构保持现状，不新增 capture_vocab 工具，不让 MCP 内置 LLM 调用
- examples 数据结构采用"definitions 内嵌 examples"方案

## 实施步骤

### 步骤 1：数据模型升级 — [models.py](file:///d:/yecll/Documents/LocalCode/vocabcraft/vocabcraft-mcp/src/vocabcraft_mcp/models.py)

**改动**：

1. 新增 `Definition` 模型：
```python
class Definition(BaseModel):
    """释义项（含关联例句）"""
    text: str = Field(description="释义文本")
    examples: list[str] = Field(default_factory=list, description="该释义对应的例句列表")
```

2. `StructuredVocab`：
   - `definitions: list[Definition]`（替换原 `list[str]`）
   - **删除** `examples` 字段
   - 新增 `model_validator(mode="before")` 兼容旧数据：
     - `definitions: list[str]` → `list[{"text": str, "examples": []}]`
     - 顶层 `examples: list[str]` 全部归并到 `definitions[0].examples`（若 definitions 为空则建空释义承载）
     - 这样旧 JSON 加载即自动转换，零数据丢失

**关键点**：用 `model_validator(mode="before")` 而非 `field_validator`，因为要同时处理 definitions 和 examples 两个字段的归并。validator 收到原始 dict，处理后 pop 掉 examples。

4. `update_vocab_from_web`（L550-584）：
   - 表单字段从单一 `definitions` textarea + `examples` textarea 改为按义项输入
   - **表单设计**（见步骤 7 模板）：每条释义一行 `释义文本|例句1;例句2`，用 `|` 分隔释义与例句，例句用 `;` 分隔
   - 服务层解析逻辑：
     ```python
     def _parse_definitions_block(value: str) -> list[dict]:
         result = []
         for line in value.replace("\r\n", "\n").split("\n"):
             line = line.strip()
             if not line:
                 continue
             if "|" in line:
                 text, ex_str = line.split("|", 1)
                 examples = [e.strip() for e in ex_str.split(";") if e.strip()]
             else:
                 text, examples = line, []
             result.append({"text": text, "examples": examples})
         return result
     ```
