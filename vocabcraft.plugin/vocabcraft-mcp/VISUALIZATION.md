# VocabCraft 可视化说明文档

## 1. 概述

VocabCraft 可视化是一个基于 FastAPI 的本地 Web 界面，用于展示词汇学习数据并支持交互式复习。
所有数据仍保存在本地文件系统（`data/` 目录），Web 层仅做只读查询；复习评分通过复用现有 `tools/quiz.py` 写入数据。

设计参考了 DeepReview 的可视化方案：单页应用（SPA）+ HTMX 局部刷新 + Alpine.js 状态管理 + ECharts 图表渲染。

## 2. 启动方式

```bash
# 方式一：使用 uv 运行
uv run vocabcraft-web

# 方式二：安装包后直接使用
vocabcraft-web
```

服务默认绑定 `127.0.0.1:8002`，仅本机可访问。打开浏览器访问：

```
http://127.0.0.1:8002
```

## 3. 页面与功能

### 3.1 概览页（Dashboard）

入口：顶部导航「概览」

- **KPI 卡片**：词汇总量、今日待复习、本周新增、已掌握词汇数
- **语言分布饼图**：按 `structured.language` 统计
- **掌握度分布柱状图**：新词 / 生疏 / 熟悉 / 掌握
- **30 天词汇增长趋势折线图**：按创建日期统计
- **今日待复习清单**：点击「开始复习」进入出题页面

### 3.2 统计页（Stats）

入口：顶部导航「统计」

- **维度切换器**：按语言 / 掌握度 / 日期 / 题型切换主图数据
- **分布统计柱状图**：当前选中维度的分布
- **题型分布雷达图**：四种题型的数量对比
- **掌握度堆叠柱状图**：掌握度分布
- **30 天词汇增长趋势面积图**

### 3.3 复习页（Review）

入口：顶部导航「复习」

- **今日待复习清单**：展示所有到期（`next_review <= 今天`）的单词，可逐个点击「开始」复习
- **开始今日复习**：一键为所有当天到期词汇生成批量复习，连续答题，结束后显示汇总
- **复习日历**：当前月份每天待复习任务数
- **艾宾浩斯遗忘曲线**：基于 SM-2 初始间隔的理论保留率曲线
- **各语言复习完成率**：按语言统计至少复习过 1 次的词汇占比

#### 批量复习流程

1. 复习页点击「开始今日复习」
2. 系统为每个到期词汇自动生成一道题（题型与单题出题一致）
3. 用户逐题作答，提交后立即评分并更新 SM-2 记忆状态
4. 全部完成后展示汇总：题数、均分、薄弱词列表、下次复习日期分布

### 3.4 词汇管理页（Vocab）

入口：顶部导航「词汇」

- **词汇列表**：展示所有词汇，支持按语言筛选、按词形搜索
- **词汇详情**：点击卡片进入详情，查看词形、音标、词性、释义、例句、复习状态
- **编辑词汇**：在详情页点击「编辑」，可修改词形、音标、词性、语言、释义、例句
- **删除词汇**：列表/详情均可删除，删除前需确认
- **独立出题**：列表/详情均有「出题」按钮，可直接为任意词汇生成考题

### 3.5 出题与评分（Quiz）

入口：Dashboard / Review 页点击「开始复习」，或在「词汇」页点击「出题」

- Web 层自包含出题逻辑，不依赖外部 LLM
- 支持四种题型：选择 / 填空 / 拼写 / 释义
- 选择题干扰项自动从同语言其他词汇中抽取
- 提交后自动调用 `grade_quiz` 评分并更新 SM-2 记忆状态

## 4. 数据流

```text

│  浏览器      │────▶│  FastAPI     │────▶│  web/routes/    │

└─────────────┘     └──────────────┘     └─────────────────┘
                                                   │
                                                   ▼
                                          ┌─────────────────┐
                                          │  web/services.py │
                                          │  数据编排/转换   │
                                          └─────────────────┘
                                                   │
                          ┌────────────────────────┼────────────────────────┐
                          ▼                        ▼                        ▼
                   ┌─────────────┐        ┌─────────────┐          ┌─────────────┐
                   │ storage.py  │        │ statistics  │          │  quiz.py    │

                   └─────────────┘        └─────────────┘          └─────────────┘
```

## 7. 安全与隐私

- Web 服务仅监听 `127.0.0.1`，不对外暴露
- 不收集用户名等个人身份信息
- 所有词汇、复习记录、考题仍存储在本地 `data/` 目录
- 图片文件保留在项目目录下，不上传到外部服务

## 8. 与 DeepReview 的差异

| 维度 | DeepReview | VocabCraft |
|------|-----------|-----------|
| 核心实体 | 错题 | 词汇 |
| 分类维度 | 学科 / 错误类型 / 知识点 | 语言 / 掌握度 / 题型 |
| 复习触发 | 错题复习 | 词汇到期复习 + 出题评分 |
| 出题方式 | 错题直接查看 | Web 层生成选择题/填空/拼写/释义 |
| 端口 | 8001 | 8002 |

## 9. 扩展建议

- 掌握度计算当前仅基于 `repetitions`，可综合 `ease_factor` 与最近复习时间优化
- 选择题干扰项当前随机抽取，可改为按词性/难度近似匹配
- 统计页可按语言细分掌握度堆叠图
- 可新增词汇列表页，支持搜索、编辑、删除
