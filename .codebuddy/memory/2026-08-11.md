## 修复 Release 工作流构建失败

`scripts/build-release.sh`（release.yml 调用）将四平台配置写入**非带点目录**（`trae/`、`opencode/`、`codebuddy/`、`goose/`），但 verify 步骤 + IDE 识别要求**带点目录**（`.trae/` 等），导致 `Missing required files` → `exit 1`，Release 工作流失败。PowerShell 版 `build-release.ps1` 一直是带点的，两者不一致。

修复：`build-release.sh` 新增 `CFG_DOT` 映射并在步骤 [2]/[3] 使用 `$STAGING_DIR/${CFG_DOT[$p]}`。本地 `bash build-release.sh 0.5.5` 复现：verify 通过（110 文件、无 .venv）；仅 `zip not found` 属 Windows 沙箱缺 zip，ubuntu-latest runner 自带 zip/zstd/tar 不受影响。

CHANGELOG 0.5.5 条目已补「修复：Release 工作流构建失败」段。
