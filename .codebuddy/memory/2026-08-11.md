# 2026-08-11

## 新增 AAIF Agent 运行时：Goose

为 VocabCraft 增加 Goose（Block 开源 Agent 运行时）支持，遵循既有 AAIF 单向同步模式。

- 新增 AAIF 真相源 `.agents/runtime/goose.json`（Goose 原生 `extensions` + `type: stdio` schema）。
- 新增 `scripts/generate-goose-config.py`：将 goose.json 转为 `.goose/config.yaml`（`uv --directory` 的相对路径在同步时解析为绝对项目路径，无需 `${workspaceFolder}`）。
- `scripts/sync-agent-configs.{sh,ps1}` 增加 `--skip-goose` / `-SkipGoose`，并把 Skills + AGENTS.md 同步进 `.goose/`。
- `scripts/pre-commit` 生成目录拦截名单新增 `.goose/*`。
- `install.{sh,ps1}` 增加 `goose` 运行时选项与下一步提示。
- README / QUICKSTART / DEPLOY / AGENTS.md / CHANGELOG 同步更新（运行时计数改为五，目录列表加入 `.goose/`、`.codebuddy/`）。

注意：Goose 当前用 2026 Block 官方 `extensions` 格式（非旧版 `mcp_servers` 顶层格式）。
